## 서문 / 前言

「갑」은 블록체인 기반 자원봉사 관리 플랫폼「HeartChain(하트체인/心链)」을 개발·운영하며,「을」은 __________(이하「자원봉사 단체」)를 운영하는 파트너로서 본 계약에 참여한다. 양측은 상호 이해득실과 공동 번영을 도모하며, 다음과 같이 계약을 체결한다.

## 제1조 (정 의) / 第1条（定义）

| 용어/术语 | 정의/定义 |
|-----------|-----------|
| **플랫폼** | 「갑」이 운영하는 HeartChain(하트체인/心链) 온라인 서비스 및 관련 APP |
| **HRT** | 플랫폼 내부 토큰「Heart Token」으로, 현 시점 단가는 미부여, 상장 시점 기준 역산에 따름 |
| **유효회원** | 플랫폼에 가입 후 **6개월 이내 최소 1회 APP에 로그인**한 회원 |
| **단체 등록인원** | 「을」를 통해 플랫폼에 가입된 회원 중 유효회원으로 판정된人数 |
| **개인이머니(个人人头费)** | 「을」의 개별 회원이 자체 추천·유치하여 가입시킨 유효회원 수 |
| **임무(タスク/任务)** | 플랫폼에 게시된 자원봉사活動 정보 |
| **임무가치(タスク価値/任务价值)** | 임무 게시 시 발행자가 설정한 HRT 표기 수치 |

## 제2조 (HRT 발행总量 및 분배 비율) / 第2条（HRT发行总量及分配比例）

「갑」은 플랫폼 토탈 HRT 중 아래와 같이 분배한다.

```
HRT 총 발행량  = 100%
├─ 30%  →  개발자 보유 ( Developer Reserve / 开发者保留 )
├─ 50%  →  단체 풀 ( Organization Pool / 团体份额池 )
│           「을」 등 파트너 단체에 人头方式分配
└─ 20%  →  개인 풀 ( Individual Pool / 个人人头费池 )
            가입 시킨 개인회원에게人头方式分配
```

> **참고**: 상기 분배 비율은 계약 체결 시점의 기준이며, 향후 플랫폼 운영 필요에 따라「갑」은「을」에게 사전 서면통보를完了条件属实同等条件下优先续约权利有义务遵守平台规则的情况下同等条件属实 우선 통보하고 갱신할 수 있다.

## 제3조 (단체 풀 HRT 부여 방식) / 第3条（团体池HRT赋予方式）

### 3.1 기본 원칙
「을」에게 부여되는 단체 풀 HRT는 **가입 시 1회성**으로 지급되며, 그 수량은 다음 산식에 따른다.

```
단체 HRT 지급总量 = 해당단체 注册人头数 × 1인당 HRT 단가
```

### 3.2 1인당 HRT 단가 산정
1인당 HRT 단가는 **상장 시점 역산 방식**으로 결정한다.

```
1인당 HRT 단가 = (HRT 총 발행량 × 50%) ÷ (전체 파트너 단체 유효회원 합계)
```

- **분자**: HRT 총 발행량의 50%에 해당하는 단체 풀总量
- **분모**: 계약 체결 기준 모든 파트너 단체의 유효회원合력
- **상장 시점 재검증**: 「갑」은 토큰上市 시 시장 환산가치에 기반하여 최종 단가를 확정하고「을」에게書面으로 통보한다.

### 3.3 지급 시기 및 방법
1. 「을」는 회원 가입 정보를 플랫폼에 입력하고,「갑」은 해당 정보를 **월 1회** 검증·확인한다.
2. 유효회원으로 판정된人数에 대해 해당월 말일 기준 **30일 이내**，「을」가 지정한 HRT 지갑주소로 전송한다.
3. 지급 완료 시「갑」은「을」에게 지급내역 명세서(人头数·단가·총액)를发送电子邮件/书面通报한다.

## 제4조 (개인 풀 HRT 부여 방식) / 第4条（个人池HRT赋予方式）

### 4.1 대상 및 방식
개인이 자체 추천·유치하여 플랫폼에 가입시킨 **유효회원**이 있는 개인회원에게, 개인 풀(20%) 내에서 HRT를 부여한다. 산식 및 단가는 제3조와 동일한 기준을 적용한다.

```
개인 HRT = 해당個人이 유치한 유효회원수 × 1인당 HRT 단가
```

### 4.2 지급 방식
개인 회원에게直接 지급하며, 지급내역은 개인 지갑 주소로 자동 반영된다.

---

## 제5조 (유효회원 인정 기준) / 第5条（有效会员认定标准）

### 5.1 유효회원의 정의
다음 조건을 **모두 충족**한 회원만 유효회원으로 인정된다.

1. 플랫폼에 정식 가입 완료한 자
2. 가입 후 **6개월 이내 최소 1회 이상 APP에 로그인**한 자
3. 플랫폼 이용약관 및 관련 규정을 위반하지 않은 자

### 5.2 검증 주기
「갑」은 매월 1일 기준으로 유효회원 수를 점검하고, 해당 수치를「을」에게 통보한다.

### 5.3 유효회원에 포함되지 않는 경우
- 가입 후 6개월 내 APP 미접속
- 개인 정보가 위조·탈퇴된 것으로 확인된 경우
- 플랫폼 정책 위반으로 정지·삭제된 계정

## 제6조 (임무 관련 장려금) / 第6条（任务相关奖励金）

### 6.1 회원 임무완성 장려금 (团体奖励)
「을」를 통해 가입한 회원이 플랫폼 상 임무를 **완성 완료**한 경우, 해당 임무의 거래 수수료(또는 발행자가 설정한 임무가치)의 **3%**를「을」에게 추가 장려금으로 지급한다.

```
团体 임무 장려금 = 임무완성 건의 임무가치 × 3%
```

### 6.2 단체 임무발행 장려금 ( Publishers奖励)
「을」가 직접 플랫폼에 **임무를 게시·발행**한 경우, 임무 게시 시 설정한 임무가치의 **10%**를「을」에게 추가 장려금으로 지급한다.

```
团体 임무 발행 장려금 = 임무가치 설정금액 × 10%
```

### 6.3 지급 시기
상기 장려금은 해당 임무완성 또는 게시 확인 후 **30일 이내**，「을」의 HRT 지갑으로 전송한다.

## 제7조 (HRT 가치 및 교환 조건) / 第7条（HRT价值及兑换条件）

### 7.1 현 시점 단가 미부여
HRT의 현금 환산 단가는 현재 시점에서 부여하지 않으며, 플랫폼 이용 활성화에 따라 향후 시장 가격이 형성될 것으로 예측한다.

### 7.2 향후 교환 가능 조건
다음 조건이 충족된 시점부터 HRT의 현금 교환이 가능하다.

1. **회원 충족**: 플랫폼 유효회원이 일정 규모(예: ____명) 이상 도달한 경우
2. **충전 체계 완비**: 회원이 HRT를充值하여サービス利用 또는 商品購賣할 수 있는 충전소 체계 구축 완료
3. **거래소 상장 또는 DEX流动性 확보**: 토큰의 시장流动性가 확보된 경우
4. **「갑」의 사전 통보**: 상기 조건 충족 시「갑」은 사전 서면통보完了条件属实的情况下优先续约权利有义务遵守平台规则的情况下同等条件属实

### 7.3 교환 방식
교환 가능 시,「을」는「갑」이 지정한 방법에 따라 HRT를 법정통화로 교환 신청할 수 있으며,「갑」은 교환 신청 접수 후 **30영업일 이내** 처리한다. 교환 시 발생하는 수수료는「을」가 부담한다.

## 제8조 (단체 의무) / 第8条（团体义务）

「을」은 다음과 같은 의무를진다.

1. 플랫폼에 가입시키는 모든 회원이 **본인의 실명·실제 정보**로 가입하도록 안내한다.
2. 회원이 유효회원 조건(6개월 내 1회 APP 접속)을 충족할 수 있도록 **정기 안내 및宣传活动**을 실시한다.
3. 회원의 개인정보 보호 및 플랫폼 이용약관을 준수하도록 교육·관리한다.
4. 플랫폼에 임무 게시 시 **위조 정보나 불법 내용**이 포함되지 않도록 확인한다.
5.「갑」의 요청이 있는 경우, 가입자 수 및 유효회원 현황에 대한 **월간 보고서를 제출**한다.

---

## 제9조 (갑의 의무) / 第9条（甲方义务）

「갑」은 다음과 같은 의무를진다.

1. 플랫폼의 안정적 운영 및 기술 유지·보수를 제공한다.
2. HRT 지급 내역을「을」에게 **정확히 통보**한다.
3. 유효회원 검증 기준 및 절차를 투명하게 공개한다.
4. 교환 가능 조건 충족 시, 정당한 교환 신청을 **합리적 기간 내에 처리**한다.
5. 계약 기간 중「을」의 파트너 지위를 희석시키거나 불이익을 주는 행위를 하지 않는다.

## 제11조 (계약 해지) / 第11条（合同解除）

1. 任一方严重违约且在对方书面催告后 **30일(30天)**内未纠正的，另一方可书面解除本合同。
2. 플랫폼 영구 운영 중단 시,「갑」은「을」에게 남은 HRT의 현금 환불을 보장한다.
3. 계약 해지 시「을」에게 이미 부여된 HRT는「을」의 소유로 유지된다.

## 제12조 (손해배상 및 면책) / 第12条（损害赔偿及免责）

1. 불가항력(천재지변, 전쟁, 전염병, 정부 규제 등)으로 플랫폼 운영이 중단된 경우,「갑」은 면책된다.
2.「을」가 회원의 위법행위나 개인정보 유출 등 본 계약 관련 의무 위반으로「갑」 또는 제3자에게 손해를 끼킨 경우,「을」는 이를 배상한다.
3. HRT 가격 변동으로 인한 투자 손실은「을」의 책임이며「갑」은 면책된다.
