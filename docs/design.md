# HeartChain 重新设计 — 设计文档

## 项目概述
HeartChain（哈特链）是一款基于地理位置的互助服务移动应用。本次重新设计以"苹果级简洁"为核心理念，采用温暖紫色调，打造直观、高效、有激励感的用户体验。

## 技术栈
- **前端**：Nuxt.js 3 + Vue 3 + Tailwind CSS
- **后端**：NestJS + TypeORM
- **数据库**：PostgreSQL (Neon)
- **部署**：Vercel (前端) + Render (后端)

### 7. 发布求助（方案B：分步4步）

**Step 1/4 — 基本信息：**
- 任务类型选择（6种）
- 任务标题
- 详细描述

**Step 2/4 — 时间 & 地点：**
- 时间要求（30分钟/1小时/今天/不限）
- GPS自动定位
- 详细地址（可选）

**Step 3/4 — 报酬 & 图片：**
- 报酬金额（원）
- 接受积分代替开关
- 图片上传（最多3张）

**Step 4/4 — 确认发布：**
- 信息预览卡片
- 匿名发布开关
- 服务条款同意
- 保存草稿 / 发布求助

## 后端API设计

### 新增接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/tasks/nearby | 获取附近任务（GPS+范围） |
| GET | /api/v1/tasks/:id | 任务详情 |
| POST | /api/v1/tasks | 发布任务 |
| POST | /api/v1/tasks/:id/accept | 接受任务 |
| GET | /api/v1/users/achievements | 用户成就数据 |
| GET | /api/v1/users/wallet | 钱包余额 |
| GET | /api/v1/users/wallet/transactions | 交易记录 |
| POST | /api/v1/users/wallet/recharge | 充值 |
| POST | /api/v1/users/wallet/withdraw | 提现 |

### 数据库新增表

```sql
-- 任务表
CREATE TABLE tasks (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  description TEXT,
  type VARCHAR(50), -- errand/transport/teach/pet/repair/delivery
  status VARCHAR(20) DEFAULT 'open', -- open/accepted/completed/cancelled
  latitude DECIMAL(10,8),
  longitude DECIMAL(11,8),
  address VARCHAR(300),
  reward_amount INTEGER DEFAULT 0,
  reward_points INTEGER DEFAULT 0,
  accept_points BOOLEAN DEFAULT FALSE,
  anonymous BOOLEAN DEFAULT FALSE,
  deadline TIMESTAMP,
  creator_id INTEGER REFERENCES users(id),
  helper_id INTEGER REFERENCES users(id),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 成就表
CREATE TABLE achievements (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  badge_code VARCHAR(50),
  badge_name VARCHAR(100),
  unlocked_at TIMESTAMP DEFAULT NOW()
);

-- 交易记录表
CREATE TABLE transactions (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  type VARCHAR(20), -- income/expense/recharge/withdraw
  amount INTEGER,
  points INTEGER DEFAULT 0,
  description VARCHAR(200),
  status VARCHAR(20) DEFAULT 'completed',
  created_at TIMESTAMP DEFAULT NOW()
);
```
